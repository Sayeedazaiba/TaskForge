# TaskForge

A Python-based Student Project Management System developed during my internship to organize and manage student project information through a simple desktop application.

## Overview

TaskForge is a desktop project management application built using Python and Tkinter. It allows users to manage student project details through a graphical user interface, with project data stored in a JSON file.

The project was developed with a focus on Python programming, Object-Oriented Programming (OOP), file handling, and building a functional desktop application.

## Features

- Add and manage student project information
- View stored project details
- Update project information
- Delete project records
- Store data persistently using JSON
- Simple graphical user interface using Tkinter
- Object-Oriented Programming based implementation

## Technologies Used

- Python
- Tkinter
- JSON
- Object-Oriented Programming (OOP)

How to Run
1. Clone the Repository
git clone https://github.com/Sayeedazaiba/TaskForge.git
2. Navigate to the Project Folder
cd TaskForge
3. Run the Application
python project_management.py

The Tkinter-based desktop application will open.

Data Storage

Project information is stored locally in project_data.json. The application reads from and writes to this file to maintain project records.
